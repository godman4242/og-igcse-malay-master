to the learner (Grammar.jsx:588) and the join key into the elaborative feedback.

## Web verification (authority, not memory)
- ber- → be- has **two distinct triggers**: (1) r-initial root → drop r to avoid double-r
  (rasa→berasa, renang→berenang, rehat→berehat); (2) first syllable carries "er" → drop r
  (ker-ja→bekerja). Sources: Ivan Lanin / KBBI (ker-ja→bekerja, ter-nak→beternak distinct rule);
  malaytuitionsg.com/fungsi-kata-imbuhan-ber.
- **MALAY-specific check that changed the fix:** considered `beternak`/`beserta` as a 2nd example,
  but **DBP PRPM (prpm.dbp.gov.my) returns "Carian kata tiada di dalam kamus terkini" for BOTH** —
  they are Indonesian, not standard Malay (Malay = `menternak`, `bercermin`). Excluded. `kerja`→
  `bekerja` is the lone clean Malay example, kept alongside the already-shipped `kerjasama`→
  `bekerjasama`.
