## Design decision (decide-and-flag)
- **Decision:** the `/mistakes` guide is **entirely centered `arrow:'none'` cards** (no DOM anchors).
- **Why:** `MistakeJournal.jsx` has TWO mutually-exclusive render states with **no element common to
  both** — a celebratory `EmptyState` (a new student with zero mistakes, the dominant guide-explorer
  case) and the populated journal. Any anchored step would skip-then-hang on the empty state (the exact
  GOAL-backlog-#5 / Bug-A class). All-centered renders identically in both states and needs **zero JSX
  changes** to the page (lowest regression risk).
- **Veto note:** if arrows-on-controls are wanted later, gate the header ▶ on `hasAnySignal` + add
  anchors — but that hides the guide from new users (worse for ADD-first onboarding).
