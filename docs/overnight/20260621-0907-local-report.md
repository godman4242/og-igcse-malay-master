## What it does
A corner grip (⤡, bottom-right of the guide popover) resizes the box (width + height) by
pointer-drag OR arrow keys (keyboard/switch parity — right/down grow, left/up shrink by 24px). The
chosen size HOLDS across Next/Back (re-applied every step render, before `reapplyDock`, exactly how
`dockedOrigin` holds). Size lives in an in-memory closure (`boxSize`) — in-session only, **no
STORE_VERSION bump**. Double-click is a full reset (default position AND size).

## Architecture (mirrors the Tslide★ pure/impure split)
- `dragDock.js` — pure `clampBoxSize(size, viewport, opts)` + `MIN_BOX_SIZE` (200×120) /
  `MAX_BOX_FRACTION` (0.9). Per-axis; non-finite→min; max floored at min so a tiny viewport can't
  invert the range.
- `guideController.js` — `boxSize`/`resizeCleanup` state; `applyBoxSize` (sets `maxWidth:none` so the
  user's width wins over BOTH the 320px theme cap and the 220px docked cap → resize works minimized
  OR floating); `startResize` pointer loop (delta tracks 1:1, one announce on release);
  `keyboardResize`; onPopoverRender wiring (applyBoxSize → reapplyDock); teardown cleanup; handle
  exports. **Self-review fix:** `restoreDefault` now also resets the size (was position-only — once
  resized there was no pointer way back to default size).
- `popoverDecorations.js` — `addResizeHandle` (pointerdown→onResizeStart, arrows→onResizeKey, both
  stopPropagation) + `.guide-resize-handle` added to `RESTORE_IGNORE` (dbl-tap on the grip must not
  yank the box to centre) + decoratePopover params.
- `index.css` — `.guide-resize-handle` (16px corner grip tucked inside the 18px bottom padding → no
  footer overlap; token colors only → dark + light safe).
