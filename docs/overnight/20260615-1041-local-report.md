## The gap (Real + Measurable + Verified)

- **Evidence:** `src/lib/study/quizOptions.js:24` `const all = Object.values(dictionary)`. Sole caller

- For an **English card** (`card.lang==='en'`, v34): `card.e` = the **Malay** correct answer; distractors

- **Reachable:** `useStudySession.js:25` scopes session to `cardsForLang(allCards, studyLang)`;
  `studyLang==='en'` serves only `lang:'en'` cards; `MODES` (`Study.jsx:18`) offers Quiz, no lang guard.
- **Measurable Done:** for an English card every distractor is a dictionary KEY (Malay), no English gloss.
