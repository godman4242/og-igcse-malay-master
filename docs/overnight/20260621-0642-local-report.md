## Decision log
- **Decision:** make the existing theme-safe `guide-explore` veil-off class the SINGLE
  backdrop-dim switch, driven by a derived predicate `freeRoam() = mode==='explore' ||
  dockedZone != null`; a new `syncFreeRoam()` recomputes + toggles it from
  pause/resume/dock/undock/drag-float AND on every step render.
  - **Why:** the dim was a pause-ONLY effect, conflating the dim axis with pause state. The
    re-steer's key insight is that DIM and CHROME are separate axes. One switch, two triggers
    (explore OR docked) is the minimal correct model and composes.
  - **Veto note:** reused `guide-explore` rather than a 2nd class because the CSS effect (veil
    off + page clickable + scroll) is byte-identical to pause's.
- **Teardown bug found + fixed mid-build:** driver.js puts `driver-active` on `<body>`
  (`node_modules/driver.js/dist/driver.js.mjs:554`) and `destroy()` removes it — so clearing
  `guide-explore` AFTER `destroy()` targeted the wrong element (`<html>` fallback), leaving the
  stale class on `<body>` → a re-opened tour started undimmed. Fixed by capturing the root
  BEFORE `destroy()`.
