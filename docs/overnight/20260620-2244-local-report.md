- `"dasar perdana"` returns only "dasar/prinsip utama" (a noun phrase); kamusbm.com glosses
  `perdana` = "yang terutama / yang pertama". Not a discourse marker.

  *kesimpulannya / konklusinya / secara tuntas*) — left untouched.

## Decision (decide-and-flag)

`"Dasar perdana,"` → `"Pada dasarnya,"` in BOTH the opening text (line 355) and its annotation
(line 358). The `exemplars.js` header invariant requires annotation phrases to appear VERBATIM
in the text or the highlighter silently drops them, so the change is coordinated.
**Veto note:** a web-verified standard connector that preserves the author's "dasar" intent
and parses correctly beats a tidy-but-broken noun phrase; `"Pada dasarnya"` chosen over a more
typical opener (e.g. "Dewasa ini") precisely because it is the minimal faithful fix.
