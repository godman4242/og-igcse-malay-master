## Shape decision (decide-and-flag)
- **ENTIRELY centered, ZERO anchors, NO JSX change** — mirrors T19 `/mistakes` + T21 `/for-you`.
- **Why:** `SavedWordCloze.jsx` has two mutually-exclusive render states with no shared anchorable
  element — a "No saved words yet" `EmptyState` (the state a fresh-store student lands in, since the
  session is built from the personal 'Saved' deck) vs the active cloze session (sentence-with-a-blank,
  typing box, Check/Show-answer, Got-it/Needed-the-answer rating). An anchored step would skip-then-hang
  on the empty state (GOAL-backlog-#5 / Bug-A class). Every step is a centered `arrow:'none'` card that
  renders identically in both → no page edit, lowest regression risk.
- **No "Try a sample":** the session is by definition over the learner's OWN saved words; there is no
  generic sample to inject (fake 'Saved' cards = a real store mutation, out of scope). Consistent with
  the other zero-anchor siblings.
- **Veto note:** if `/saved-cloze` ever gains an always-mounted setup screen (like Dictation/Cloze-
  Listening), switch to the 2-anchor + centered-summary shape.
