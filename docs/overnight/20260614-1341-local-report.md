## The gap (evidenced)
`src/data/grammar.js` taught the morphology of `mengejar` **wrong** in two places:
- `prefix-meN-kejar` drill (line 11): `kejar → mengejar` labelled `rule: 'menge- + 1-syllable'`.
- `GRAMMAR_RULES['meN-']` (line 150): listed `mengejar` as a `menge- + 1-syllable` example.

"kejar" is **two syllables** (ke-jar); `mengejar` is the **k-drop** form (`meng-` + kejar → k elides),
identical to the app's own correct `karang → mengarang` drill. The `menge-` allomorph applies **only to
monosyllabic (ekasuku) roots** (cat→mengecat, lap→mengelap, bom→mengebom). Teaching a student that "kejar"
is monosyllabic and uses menge- is a confident-wrong lesson.

## Web verification (content, not memory)
- [Kuih Bahasa — Imbuhan meN-](https://kuihbahasa.com/imbuhan-men/): menge- = one-syllable root words.
- [Cikgu Tan CL — Imbuhan menge- dan kekecualiannya](http://cikgutancl.blogspot.com/2016/02/informasi-bahasa-imbuhan-menge-dan.html): ekasuku list (bom, cat, lap, tin, …).

## Change (surgical — 2 data lines + 1 new test)
- Drill `rule`: `'menge- + 1-syllable'` → `'meng- + k → k drops'` (an existing valid `GRAMMAR_FEEDBACK`
  key, so the drill's elaborative feedback now shows the correct karang/kira/kupas k-drop family).
- Reference example: `'mengecat, mengejar'` → `'mengecat, mengelap'`.
- The **answer is unchanged** (`mengejar`) — only the taught *reason* is corrected.
