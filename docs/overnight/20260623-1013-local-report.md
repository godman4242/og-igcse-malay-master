## Fix (surgical)
`advancing` is now the SHARED flag. `handlePrev` and `jumpTo` early-return when it is set, set it
`true`, and reset in a `finally` (mirroring `handleNext`). `jumpTo` validates its range BEFORE
engaging the flag, so an out-of-range/non-numeric jump stays a pure no-op (never blocks a
concurrent nav). While ANY nav is in flight, every other handler is a no-op.

Files: `src/lib/guide/guideController.js` (guard added to `handlePrev` + `jumpTo`, comment
updated), `src/lib/guide/__tests__/guideController.test.js` (+3 tests).
