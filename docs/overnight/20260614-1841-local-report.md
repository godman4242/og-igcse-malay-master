## Gap (Real · evidenced)

> `2. **The same:** sekeluarga (one family/same family), sekolah (school — lit. "one group")`

`sekolah` ("school") is **borrowed from Portuguese `escola`** — the "se-" is part of the loanword, not the Malay
prefix se-, and there is no Malay root "kolah" = "group". So "lit. 'one group'" is a fabricated etymology that
mis-classifies a loanword as an affixed word — the exact false-affix trap IGCSE imbuhan questions test. Same
confident-wrong-content bug class as the `penjadi`/`kejar`/`penulis` fixes. This was the pre-thought `▶ NEXT` thread
of the prior `imbuhan-an` ship.

## Verified (content web-checked, not memory)
- `sekolah` ← Portuguese `escola`; "se-" not an affix; no root "kolah" = "group":
  Wiktionary (https://en.wiktionary.org/wiki/sekolah), List of loanwords in Malay
  (https://en.wikipedia.org/wiki/List_of_loanwords_in_Malay_language).

  (https://bobo.grid.id/read/084046949/makna-penggunaan-imbuhan-se-dan-contoh-katanya-materi-bahasa-indonesia).
