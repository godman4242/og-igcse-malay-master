## Fix
Replaced the arbitrary-`.includes()` clause with `containsWholeWord(card.e, trimmed)` (`src/lib/wholeWordMatch.js`, the
Unicode whole-word boundary already used by the scorecard + cloze-blank fixes). Least-behaviour-change: only sub-word
fragments flip true→false; every whole word / "/"-alternative stays correct (95 dict glosses use "/", 192 are multi-word).

## Decision log

  "brother" for "older brother" (real over-strictness regression).
