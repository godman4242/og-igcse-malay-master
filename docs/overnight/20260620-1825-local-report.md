## Decision log
- **Decision:** DOM-split each footer button's `"icon + word"` into `.guide-btn-ico` +
  `.guide-btn-label` spans in `decoratePopover`, hide the label span via CSS when `.guide-docked`.
  - **Why:** driver.js owns Back/Next/Done creation and resets their text each render, so I can't
    feed pre-split markup at config time; post-processing each render is the only seam. CSS-only
    visibility toggle = dark/light safe (no color tokens).
  - **Veto note:** if a future control crowds the footer even when floating (T1's real trigger),
    revisit the one-line-never-wrap CSS then.
- **Decision:** set `aria-label`=the word on the icon-only nav buttons (only when absent) so screen
  readers keep a name and `getByRole('button',{name:/Next/i})` still resolves while docked; never
  clobber the Pause button's richer "…explore the page" label. (This is an a11y improvement.)
- **Scope:** hover/focus re-expand ONLY. Double-click-restore is T6 (Phase 4) — clamped out.
