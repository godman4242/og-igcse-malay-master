## Shape decision (decide-and-flag)
**Decision:** anchored shape (2 anchors) like T15–T18, NOT the all-centered shape of T19/T21.
**Why:** unlike `/mistakes` + `/for-you` (mutually-exclusive empty-vs-populated states with no shared
element), WordFamilies has a STABLE always-populated landing — the search input renders
unconditionally and the static 41-root grid always shows its first card on arrival (the empty state
only appears on a no-match SEARCH, never at guide launch). So arrows can safely point at landing
controls. The tree + its speak/add controls mount only after a root expands, and the mistakes panel is
conditional → both are taught in the centered summary (no selector → never skip-hangs / no Bug-A class
empty-state hang). **One-line veto:** if a future refactor makes the root grid conditional on data,
move the roots step to a centered card (same as the tree summary).
