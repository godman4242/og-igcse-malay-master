# AI / Cikgu Maya architecture

> Reference doc — read this when touching the AI tutor tiers, the expert-system KB, the confidence gate, or the BYOK instruct router. Pointer lives in `CLAUDE.md` → Architecture. Every-session invariants (OpenRouter slugs rotate → discover; keys never touch the store) are duplicated in `CLAUDE.md` → Critical Conventions, so they stay enforced even without this file loaded.

**In short** — the summary root `CLAUDE.md` carried until 2026-09-26 (it now keeps one line + a pointer here):

Three-tier fallback chain (cost-optimized): **(1) Expert system** (default, free) — rule-based KB in `src/data/cikguKnowledge.js` (33 entries) with fuzzy keyword search, **confidence-gated** (`getExpertResponse`, `MIN_CONFIDENCE = 40`) so a weak/off-topic match hedges honestly instead of bluffing (confident-wrong is the worst failure for a learning tool); **(2) OpenRouter free models** (`VITE_OPENROUTER_KEY`); **(3) Supabase Edge Function** OpenRouter `:free` proxy (SSE, circuit breaker, 50 calls/day per account, server-enforced). Mock mode: `VITE_AI_MOCK=true`. **Separate BYOK instruct seam** (`src/lib/instruct.js`, frozen `hasInstructProvider()`/`callInstruct()`): multi-provider router; **keys live in per-provider localStorage, NEVER the Zustand store** (so they can't reach the cloud blob); 429 → cooldown + auto-switch.

Three-tier fallback chain (cost-optimized):
1. **Expert system** (default, free): Rule-based knowledge in `src/data/cikguKnowledge.js` with fuzzy keyword search. **33 entries** spanning IGCSE grammar/vocabulary/writing/speaking/exam topics — incl. a **peribahasa bank** (~15 proverbs, each meaning + essay theme), **rencana/laporan/syarahan** format skeletons, a **formal vocab-upgrade** entry, **kata ganda** (reduplication), and **golongan kata** (word classes) (widened 2026-06-14). **Confidence-gated (2026-06-14):** `searchKnowledge`'s `scoreMatch` scrapes a point off almost any query, so the top match is almost never empty — a weak/off-topic match used to be presented as authoritative (confident-wrong, the worst failure for a learning tool). The shared pure `getExpertResponse(query)` (moved here from `CikguBot.jsx` — the page AND the AI-tier eval's `freeCikgu` import the SAME fn, no more replication) now gates on `MIN_CONFIDENCE = 40`: below it (or no match) it returns an honest uncertainty reply (`confident:false`) that names the closest topic it found + points to the free AI tutor (a suggestion, never a paywall), instead of bluffing. **The threshold is CALIBRATED keyless from `scripts/ai-tier-eval/goldCikgu.mjs`** — every genuinely-strong match scores ≥49, the whole ambiguous floor ≤31 (empty gap 32–48); raw score cannot separate weak-but-correct from off-topic (the in-coverage "penjodoh bilangan" Q and the out-of-coverage "bagai aur dengan tebing" Q both score exactly 28), so the gate gates the whole floor — out-of-coverage confident answers drop 3/3→0/3 at the cost of 2 weak in-coverage Qs hedging (those 2 — penjodoh, dari/daripada — were RECOVERED by the KB widening below). `formatKnowledgeResponse`, the "Related" logic, and `searchKnowledge`'s return shape are untouched. The harness's `[Cikgu · FREE confidence gate]` table reports the keyless before/after. **KB WIDENING (2026-06-14):** added the peribahasa bank + rencana/laporan/syarahan + the formal vocab-upgrade entry and boosted the penjodoh/kata-sendi keywords → the gate table moved to `in` **9/9** · `partial` **4/4** · `out` **0/3** (3 *fresh* out-of-scope gold Qs keep the safety-net bucket non-empty at 0 confident — every in/partial gold question now answers; only the deliberately out-of-scope ones hedge). A grounded correctness audit (web-sourced vs DBP/SPM guides) caught + fixed one confident-wrong proverb spelling (pembentung→pembetung). Entries are authored as **general IGCSE syllabus content** — `goldCikgu.mjs` keyFacts are the independent answer key (the KB is the contestant), never reverse-engineered into the entries; coverageHint metadata was reclassified out→in for the 3 now-covered Qs but keyFacts are untouched.
2. **OpenRouter free models** (`src/lib/openrouter.js`): DeepSeek R1, Llama 4 Scout, Gemma 3. Requires `VITE_OPENROUTER_KEY`.
3. **Supabase Edge Function** (`supabase/functions/ai-proxy/index.ts`, called by `src/lib/ai.js`): OpenRouter `:free`-model proxy with SSE streaming, circuit breaker (3 failures → 120s cooldown), 50 calls/day per account — enforced server-side since 2026-09-26 (see below); the client-side count is UX only.

### Server code that spends the OWNER's keys (reviewed 2026-09-26)

Three surfaces run on keys the owner pays for (or whose quota every learner shares). Each one: **a real signed-in account** (GoTrue `/auth/v1/user` — the gateway's `verify_jwt` lets the public publishable key through, probed live) → **body validated and size-capped** → **counted** (`increment_api_usage` RPC, per UTC day) → provider. Errors never relay the provider's body or status (429 excepted).

| Surface | Key | Per account / all accounts (env override) | Body cap | Notes |
|---|---|---|---|---|
| `api/gemini.js` | `GEMINI_KEY` (live; **free tier** — no billing account exists, checked 2026-09-26) | 50 / 500 (`GEMINI_DAILY_CAP`, `GEMINI_ALL_ACCOUNTS_DAILY_CAP`) | 128 KB, **text parts only** | output ≤ 2048 tokens; `tools`/media/`cachedContent` refused or dropped |
| `api/translate.js` | `DEEPL_KEY`, `GOOGLE_TRANSLATE_KEY` (**not set in prod**) | 100 / 1000 (`TRANSLATE_…`) | 100 texts, 30k chars | counts requests, but providers bill characters — set a provider quota before adding a key |
| `ai-proxy` edge fn | `OPENROUTER_API_KEY` (`:free` models, $0) | 50 / none | 64 KB | OpenRouter's per-key free quota is the shared ceiling; client `system` turns are rebuilt as `user`; model list ends with `openrouter/free`; CORS from the `ALLOWED_ORIGINS` secret (must list the live origin) |

The all-accounts row (nil UUID in `api_usage_counters`) exists because signup is open: without it, N minted accounts = N × the cap. It **fails closed** (it is the spend bound); per-account caps fail open. A cap of `0` is a working kill switch (`capFromEnv` in `api/_lib/guard.js`). Tests: `api/__tests__/{gemini,translate}.test.js`, `api/_lib/__tests__/guard.test.js`, `src/lib/__tests__/aiProxyHandler.test.js`. Deploy the edge fn separately: `supabase functions deploy ai-proxy --project-ref sfrpbnmhvhtsgzqwnent --use-api`.

**Shared BYOK chat prompt:** the Gemini (`gemini.js`) and OpenRouter (`openrouter.js`) Cikgu chat tiers BOTH import ONE `CIKGU_SYSTEM_PROMPT` from `src/core/agent/promptLibrary.ts` (single source of truth, unified 2026-06-12 to direct-instruction — lead with the answer + worked example, not Socratic). Its `WHAT TO TEACH` list is kept at **syllabus parity with the free expert KB** (incl. peribahasa-with-essay-theme, penjodoh bilangan, kata ganda, golongan kata; extended 2026-06-14). Pinned by `src/lib/__tests__/cikguSystemPrompt.test.js` (both providers send it verbatim) and mirrored byte-for-byte in the eval's `CIKGU_BYOK_SYSTEM` (`scripts/ai-tier-eval/prompts.mjs`) — change one, change all three.

Mock mode: `VITE_AI_MOCK=true` returns canned responses from `src/data/aiMocks.js`.

**Instruct seam (BYOK-only, separate from the chain above):** `src/lib/instruct.js` is a multi-provider router over `src/lib/instructProviders/{openrouter,gemini,ollama}.js` (adapter contract `{id, label, hasKey, call, verify}`). Public API is frozen: `hasInstructProvider()` / `callInstruct(args)` — callers never import an adapter directly. Keys live in per-provider localStorage slots (`igcse-openrouter-key`, `igcse-gemini-key`, `igcse-ollama-url/-model`) — NEVER the Zustand store, so they can't reach the cloud blob. Env keys never count. Gemini BYOK calls the NATIVE `generateContent` endpoint with the `x-goog-api-key` header (the OpenAI-compat endpoint CORS-fails client-side) and never touches `/api/gemini`. Quota 429 → exponential cooldown (120s ×2, cap 30 min) + auto-switch to the next configured provider + a throttled Layout toast (`InstructSwitchToast`). Spec: `docs/superpowers/specs/2026-06-10-multi-provider-instruct-router-design.md`.
