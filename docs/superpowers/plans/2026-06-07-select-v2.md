## Step 1 — pure `classifyGesture` (TDD)  ✅ DONE 2026-06-07
Shipped: `src/lib/gestureModel.js` `classifyGesture({button,startIndex,endIndex}) →
{kind:'word'|'words'|'phrase', startIndex, endIndex}` (Kheshav's mapping: right-drag→'phrase',

PDFReader `handleCommit` switches on `kind`; the Tips footer text was corrected. +5 unit tests.

## Step 2 — "group into a phrase" action (TDD-able pure part)
Per Q2 (default = right-click on an existing selection):
- Pure helper in `gestureModel.js` (or `selectionToCard.js`): `groupSelection(selection,
  fromIndex, toIndex)` → a new selection array where the covered contiguous WORD entries are
  replaced by one `{ word: joined, type:'phrase' }` (drop the per-word `en` so it re-translates).
  `ungroupSelection` reverses (split on space back to words). Pure. Unit-test both, incl.
  group-of-one = no-op, non-contiguous = ignore, idempotence.
- Wire into PDFReader: a right-click handler on the selection (or selected token range) calls
  `groupSelection`, then re-runs `translatePhrase` for the new phrase entry. §2 teaching
  moment: when grouped, also fetch `translateMany(parts)` and show "jam = … · tangan = … →
  **jam tangan = …**" in the bucket chip / a small popover.

## Step 2.5 — TOUCH support for select mode (NEW — the go-wild finding, do NOT skip)
PDF select is mouse-only today → unusable on phones (primary device). Options, pick at kickoff:
- **Recommended:** add `onPointerDown/Move/Up` to `useSelectionMode` (Pointer Events unify
  mouse+touch+pen) — but pointer has no right-button on touch, so pair it with an explicit
  **mode chip**: a small "Group ⟷ Individual" toggle in the select toolbar that decides whether
  a touch-drag produces `'phrase'` or `'words'`. Mouse keeps the button-based shortcut; touch
  uses the toggle. `classifyGesture` gains an optional `touchIntent` param (TDD: touch+drag+toggle
  → expected kind) so it stays the single source of truth.
- Verify on the 390×844 e2e viewport with touch emulation (`page.touchscreen` / dispatch
  pointer events). A "group" affordance phones can actually perform is REQUIRED before shipping.
